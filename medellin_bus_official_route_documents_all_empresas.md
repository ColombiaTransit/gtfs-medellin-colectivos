# Medellín Bus Companies — Official Route Documents

This table extends the company/route inventory in
[`medellin_bus_empresas_routes.md`](medellin_bus_empresas_routes.md) with an
official-document index.

The **Empresa** and **Código(s) de ruta** values below are taken from the
current company/route inventory. Route codes are preserved as published there,
including variants and special services.

This is **step 1 only**: it records official administrative documents and
source URLs where identified. Frequencies, schedules, dispatch intervals,
vehicle requirements and detailed route fichas will be extracted later.

## Source notes

The company and route-code inventory is based on the Alcaldía de Medellín
**Listado de depósitos de buses en Medellín** and the expanded route-code
entries in the repository source file. citeturn0view0

The official Secretaría de Movilidad management report is used above as an
official **document index** where the underlying resolution PDF has not yet
been located. It should not be interpreted as meaning that the underlying
resolution has already been examined.

The 2015 Gaceta documents are direct official sources. For example,
Resolución 1169/2015 covers the Palenque Robledal route restructuring, while
Resoluciones 1166/2015 and 1167/2015 cover other Sistema de Rutas 2A
operators.

## Notes on the source inventory

- Route codes are preserved exactly as they appear in the repository source
  table; no historical/current route-code reconciliation is attempted here.
- `Transportes Castilla` and `Transporte Medellín Castilla` are retained as
  separate entries because they occur separately in the source inventory.
- `Flota La V` and `Flota la V` are retained separately for the same reason.
- `Flota La Milagrosa` and `Flota la Milagrosa` are retained separately.
- `Cootrasana` has no route code specified in the source inventory.
- `Varias` is retained because it is the operator value in the source
  inventory for routes 281, 282, 283 and 288.
- The `(Empresa no especificada)` entry for `024 Barrial` is retained.
- The overlap of route codes between Coonatra and Conducciones América is
  preserved; no attribution has been inferred or corrected.
- No C6 information is added.

- route name

- destination
- first departure

- Saturday frequency
- Sunday frequency
- holiday frequency
- dispatch intervals
- route length

Those values should be kept in a separate structured dataset so that the
historical administrative evidence remains traceable to its source document.
